How they work:

extends Error: each class is a kind of Error, so it can be thrown and caught like any other error. It just carries extra information: fileName for one, and requestId and problems for the other.
super(...) passes the message up to the built-in Error, so error.message works.
this.name sets the label printed in front of the message.
Throwing: loadRequests throws a FileLoadError when reading or parsing fails. validateRequest throws a ValidationError when it finds problems.
Catching: each catch uses instanceof to check which kind of error arrived. Anything unexpected is thrown again with throw error, so real bugs aren't hidden.
